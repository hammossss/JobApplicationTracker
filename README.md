# JobApplicationTracker

## Översikt- JobApplicationTracker är en applikation designad för att hjälpa användare att spåra och hantera sina jobbsökningar. 
Med en användarvänlig gränssnitt kan användare registrera, uppdatera och övervaka sina ansökningar, samt hålla reda på viktiga datum och statusar.

## Funktioner- 
**Registrera ansökningar**: Lägg till nya jobbsökningar med detaljer som företag, position och ansökningsdatum.- 
**Uppdatera status**: Håll koll på statusen för varje ansökan, inklusive om den är under granskning, avslagen eller anställd.- 
**Notiser**: Få påminnelser om viktiga händelser relaterade till dina ansökningar.- 
**Filtrering och sökning**: Filtrera ansökningar efter status eller datum, och sök enkelt efter specifika jobb.
